## Proyecto

Es una aplicación CMS para la gestión de una biblioteca física personal.

## Comandos

## Comandos

- Ejecutar aplicación: `php artisan serve`
- Tests: `php artisan test`
- Lint/format: `./vendor/bin/pint`

## Estilo y convenciones

- Laravel 12 + Blade + Tailwind.
- Código y comentarios en inglés.
- Variables, funciones, clases y métodos en inglés, siguiendo las convenciones de Laravel y PHP.
- Los nombres deben ser descriptivos y evitar abreviaturas innecesarias.
- Textos visibles para el usuario en español.
- Estilo visual del frontend: rústico, claro y fácil de usar.

## Reglas

- Lee `docs/constitution.md` y la spec activa antes de modificar el código.
- No inventes requisitos ni comportamiento.
- Ante una decisión relevante de arquitectura, diseño, accesibilidad, testing o persistencia de datos, pregunta antes de implementarla.
- Para decisiones menores de implementación que no afecten a esos aspectos, utiliza la solución más simple y coherente con el proyecto.
- No modifiques los requisitos de una spec para adaptarlos a la implementación.
- Si detectas una contradicción entre la spec y el código existente, detente y pregunta.

## Al terminar cualquier tarea

- Verificación obligatoria: ejecutar y pasar los tests relevantes.
- Añadir los cambios relevantes a `log.md`.
- Actualizar `README.md` cuando corresponda.
- Informar de los cambios realizados y de las verificaciones ejecutadas.
- No crear un commit hasta que el usuario lo autorice.
